# Supporting evidence

See kaust sisaldab portfoolio uurimisraporti kontrollitavat tekstipõhist evidence'it.

## Avaliku versiooni ulatus

- Kohalikud Windowsi rajad on üldistatud.
- AAT-005 kolm ekraanipilti jäid privaatsesse auditipakki. Piltidel on konto kasutajaliides ja privaatse NotebookLM-i URL-i osa.
- Testitulemused, promptide sisu, räsid ja teadaolevad piirangud säilisid.
- Sisemised originaalid asuvad Allani privaatses tööruumis.
